# Контракт бібліотеки InterpolationDLL (Варіант 3: Інтерполяція та апроксимація)

- **Версія API:** 1.0
- **Угода зв'язування:** `extern "C"` (C-ABI), типізація `double` та `size_t`.
- **Керування пам'яттю:** бібліотека не виділяє динамічну пам'ять і не повертає вказівники, які треба звільняти; усі вихідні масиви виділяє викликач[cite: 24].

## Експортовані функції

1. `double interp_lagrange(const double* xs, const double* ys, size_t n, double x)`
   - **Призначення:** значення інтерполяційного полінома Лагранжа в точці `x` за вузлами `(xs[i], ys[i])`.
   - **Повертає:** обчислене значення або `NaN` при помилці.
   - **Граничні умови:** `xs == nullptr`, `ys == nullptr`, `n == 0`, нескінченність/`NaN` у даних або `x`, збіжні значення `xs` (`|xs[i] - xs[j]| < 1e-12`).

2. `double interp_linear(const double* xs, const double* ys, size_t n, double x)`
   - **Призначення:** кусково-лінійна інтерполяція в точці `x` (за межами інтервалу — лінійна екстраполяція крайнім відрізком).
   - **Повертає:** значення або `NaN` при некоректних аргументах.

3. `int interp_batch(const double* xs, const double* ys, size_t n, const double* query_xs, size_t m, double* out_ys, size_t out_cap, size_t* out_count, int mode)`
   - **Призначення:** обчислення значень у масиві `query_xs` довжини `m`; `mode = 0` — лінійна, `mode = 1` — Лагранжа.
   - **Повертає:** `0` — успіх; `-1` — некоректні вказівники, розміри (`n == 0`, `m == 0`), невідомий `mode` або `NaN`/дублікати `xs`; `-2` — `out_cap < m`. Записує кількість елементів у `*out_count` (якщо `out_count != nullptr`).

4. `double interp_error(double exact_y, double approx_y)`
   - **Призначення:** абсолютна похибка `|exact_y - approx_y|`.
   - **Повертає:** `|exact_y - approx_y|` або `NaN`, якщо один з аргументів не скінченний.
